## Problem

National stock take operations (STO) were handled through fragmented spreadsheets and manual cross-checks between SAP and local warehouse reports. This created delays and made escalation difficult.

## Solution

I built StockFlow as an offline-capable web platform to standardize STO execution across sites. The system imports SAP MB52 and WMS exports, flags mismatches automatically, and tracks issue ownership.

## Tools Used

- Next.js App Router for a fast, responsive interface.
- Supabase for centralized operational records.
- Python data scripts for SAP/WMS validation logic.
- SAP MM transaction data as the source of truth.

## Impact

- Reduced reconciliation cycle from multi-hour manual work to under one hour for most STO batches.
- Improved audit-readiness by centralizing evidence and correction history.
- Enabled clearer coordination across warehouse teams, admins, and supervisors.
